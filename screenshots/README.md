The initial CurseForge file is **0.8.0**. The collapse controls and related new
settings are from **0.8.1**, so gallery captions must identify that version when
showing those features before its release. Uploading gallery images does not
publish a new addon version.

Full originals are retained in the owner's local deliverables, outside this
repository, because they contain unrelated game chat. These gallery crops are
not included in the install ZIP. Ignite, Mana Gem, and Evocation demonstrations
still need a higher-level mage.
